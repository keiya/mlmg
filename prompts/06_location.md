# 出力フォーマット指示

各ロケーションを以下のテンプレートで記述してください。ID は **`[a-z][a-z0-9_]*` の英数字スラッグ**で 2〜32 文字。時間帯バリエーションは ID にエンコード (`rooftop_morning`, `rooftop_night`)。

```markdown
## {location_name} ({location_id})

### 基本情報
- 種別: 屋内 / 屋外 / 自然 / 人工 / etc.
- 時間帯: 朝 / 昼 / 夕 / 夜 / 任意

### 視覚的特徴
- 全体の印象: ...
- 構造・広さ・天井の高さ: ...
- 主要要素 (机/木/建物 etc.): ...
- 色味・光源: ...
- 雰囲気・空気感: ...
- 特徴的な小道具・モチーフ: ...

### 物語上の使われ方
- この場所で起きる主なシーン: ...
- このロケが象徴するもの: ...
```

「視覚的特徴」セクションは設定画生成プロンプトに**直接流す**ので、画にしやすい具体表現で書いてください。

主要ロケだけ、`## ロケ名 (id)` 見出しでセクションを連結して出力してください。
