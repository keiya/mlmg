あなたは漫画の美術担当 (背景設定) です。
MPBV と Style Guide を踏まえて、この短編漫画に登場する **主要ロケーション全部** を Markdown 形式で設計してください。

主要ロケの上限は **{{ max_locations }} 箇所**。

**1 location = 1 設定画**。同じ施設の異なるアングル（例: コンビニ店内 / レジ前 / バックヤード / 外観 / 売り場）は **必ず 1 つの location にまとめる** こと（コンビニ全体を 1 ロケ `convenience_store`）。アングルやサブエリアは PageBeat の `Visual` / `Camera` フィールドで指定するので、location 設定で分裂させない。

同じ場所でも **時間帯や季節** が物語上重要に変わる場合（朝の屋上 vs 夜の屋上）のみ、別 ID として分けてよい（`rooftop_morning` / `rooftop_night`）。ただしこれも基本は同一 location 1 つで済むなら 1 つにする方向で。

短編 4-24 ページの規模なら、location は **2-4 個** に収まるのが標準。`max_locations` 上限ギリギリまで使う必要はない。

# 出力フォーマット指示

各ロケーションを以下のテンプレートで記述してください。ID は **`[a-z][a-z0-9_]*` の英数字スラッグ**で 2〜32 文字。

「視覚的特徴」セクションには **施設全体を 1 枚の設定画に描けるレベルの統合的な描写** を書いてください（特定アングルだけの記述に偏らない）。コンビニなら「売り場の全体像 + レジ + 主要な棚配置」が 1 枚で見える状態を想定。

```markdown
## {location_name} ({location_id})

### 基本情報
- 種別: 屋内 / 屋外 / 自然 / 人工 / etc.
- 時間帯: 朝 / 昼 / 夕 / 夜 / 任意

### 視覚的特徴
- 全体の印象: ...
- 構造・広さ・天井の高さ: ...
- 主要要素 (机/木/建物 etc.): ...
- 色味・光源: ...
- 雰囲気・空気感: ...
- 特徴的な小道具・モチーフ: ...

### 物語上の使われ方
- この場所で起きる主なシーン: ...
- このロケが象徴するもの: ...
```

「視覚的特徴」セクションは設定画生成プロンプトに**直接流す**ので、画にしやすい具体表現で書いてください。

主要ロケだけ、`## ロケ名 (id)` 見出しでセクションを連結して出力してください。
